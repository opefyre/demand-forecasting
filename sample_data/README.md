# Sample inputs

## Current sales-only customer/product demo

`customer_product_journey_demo.csv` contains 36 months, two invented customers,
two SKUs and quantities in tonnes. Import it as sample data; map date/customer/SKU/
qty, choose Each customer & product and Gregorian monthly totals. No group ID is
required. `customer_product_journey_orders_demo.csv` contains partial fulfillment,
above-estimate orders and a cancellation, dated October 2026. Use a reviewed complete
order snapshot only for this synthetic example. These values are not client data
or evidence of real-world accuracy. See docs/SALES_JOURNEY_ACCEPTANCE.md.

## Legacy operation fixtures — preserved, outside current product scope

The inventory/production instructions below describe earlier fixtures, not the
current sales workflow or remaining delivery requirements.

## Iran manufacturing sample

Use these files for the primary end-to-end sample:

1. `iran_manufacturing_history_60m.csv` — 60 months of synthetic Qazvin manufacturing history.
2. `iran_manufacturing_scenario_12m.csv` — 12 months of explicit operating and external assumptions.
3. `iran_scenario_event_notes.csv` — human-readable scenario documentation; it is not a model input.
4. `iran_operations_master.xlsx` — BOM, material master, open POs, capacity calendar, relationships and promotions.
5. `iran_actuals_followup_3m.csv` — three synthetic closed periods for forecast-value-add testing.
6. `inventory_demo.csv` — three synthetic finished-goods stock records. Import
   through Data → Inventory, identify as Sample/test data, use closing date
   2026-08-31, and map Status: Usable → usable, Hold → on hold. It covers only two
   products; missing products must remain unknown. Compare against a September
   2026-starting synthetic forecast in Supply → Inventory. These figures are not
   client stock and are not generated by the sample generator below.

The sample covers 12 product/customer demand streams, inventory and safety stock, production capacity, BOM consumption, purchase orders, MOQ, supplier lead times, quality holds, product relationships, promotions, USD/IRR, inflation, industrial production, pulp prices, weather, energy curtailment, logistics, Iranian working days, and events. Every value is synthetic and intended only for validation and demonstration.

Regenerate it with:

```bash
.venv/bin/python scripts/generate_iran_sample_data.py
```

## Multi-step production verification

`routed_history_demo.csv` contains 36 months of invented constant KBlank demand.
Its matching workbook is `outputs/01a0a5ce-routing/synthetic_routed_production.xlsx`.
The sample has two products, shared machines and batch setups. It is a calculation
fixture, not evidence of forecast accuracy or confirmed client manufacturing data.
Use the sample classification and 2026-08-31 stock date. Mapping, exact arithmetic
and remaining limitations are recorded in `docs/ROUTED_PRODUCTION.md`.
# Repeat-import verification

`repeat_import_initial.csv` and `repeat_import_updated.csv` are synthetic six- and
seven-month files with custom column names. They exercise reviewed mapping reuse
and immutable dataset versions; they are not client data or accuracy benchmarks.

## Dated factor import

`factor_observations_demo.csv` is an invented index, not actual Iranian inflation or
FX data. It contains one revision and a missing April. Import as Demo sample, monthly,
with period_end → Period end, value → Value, published → Publication date. Use
"Index points (synthetic)" and an explicitly synthetic location/source description.
The January value is 100 before March 10, 2025, and 101 after that day's release.
Saved factors remain context-only; see `docs/FACTOR_IMPORTS.md`.
# Iran date/unit demonstration

`iran_fx_normalization_demo.csv` is synthetic, not real FX data. Import as Persian
(Jalali) dates, Tehran release time, monthly demo sample, USD / factory settlement /
actual settlement / toman / quote quantity 100. The first row becomes 950,000 IRR
per USD. One later revision and one missing Persian month deliberately exercise
review; do not treat it as a complete forecasting factor history.

## Connected factor export demo
